### Тестовое задание на должность Младший инженер по робототехнике

*Работа была выполнена при активном использовании нейросетей с приоритетом скорости*

В силу отсутствия опыта и детального понимания поставил себе задачу сбора статистики в виде телеметрии выполняемых манипуляций.
Результат работы представлен в виде следующих графиков:
- 2d_trajectory_curves
- 3d_spatial_trajectory
- tracking_telemetry_curves
Также данные преобразованы в CSV-файл.
